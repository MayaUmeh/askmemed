# AskMeMed

Made by Maya Umeh for the Ankura AI by Design task (Scenario 3: Pharma).

It helps staff answer questions about medicines using approved documents. A person checks every reply.

All medicines and data are made up: Nazaski (period pain), Maricinta (painkiller) and Delinera (chlamydia treatment).

## How to open it

Open the website link, or download the files and double click `index.html`.

## Things to try

- `How should I store Nazaski?` gives a draft with a reference.
- `My name is Sam Lee, 07700 900123. I am pregnant, can I take Nazaski?` hides the name and number, and sends it to an expert.
- `Since taking Nazaski I have had really bad stomach pain.` goes to the safety team.
- `What is the price of Delinera?` gives no reply, because there is no approved answer.

Then try the Log and Tests tabs.

## Files

- `index.html`: the page
- `style.css`: how it looks
- `data.js`: the made up medicines and test questions
- `engine.js`: hides details, checks for risks, finds answers
- `app.js`: buttons, log and tests

I used Claude (an AI assistant) to help build this, and checked and tested it myself.
