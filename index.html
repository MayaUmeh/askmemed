How it works

  1. Hide personal details: names, emails, phone numbers, NHS numbers, postcodes and dates are hidden first.
  2. Check for risky questions: simple rules look for overdoses, side effects, pregnancy, children, unapproved uses and product comparisons. These always go to a person.
  3. Search: the tool finds the best matching sections in the approved documents.
  4. Draft: the reply is built only from approved text, copied exactly, with a reference after each part. If nothing matches, it goes to an expert.
  5. Person checks: nothing is sent until a named reviewer ticks two boxes. Expert questions cannot be approved here at all.
  6. Log: every decision is saved, with the sources and whether the draft was changed.

What this is not

This is a small demo with made up data. It is not real medical advice. Before using it for real, the rules would need to be checked by medical and safety experts.
